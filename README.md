# 🐧 Linux User Management System

> **Bash Automation Project | Linux Administration**

A practical Bash script for automating common **Linux user and group management tasks** through an interactive CLI menu.

---

## ✨ Features

| Feature             | Description                             |
| ------------------- | --------------------------------------- |
| 👤 Create User      | Create a Linux user with home directory |
| 🗑️ Delete User     | Remove an existing user                 |
| 🔑 Password         | Change user password                    |
| 🔒 Lock User        | Lock a user account                     |
| 🔓 Unlock User      | Unlock a user account                   |
| 👥 Group Management | Add/remove users from groups            |
| ℹ️ User Info        | Display user details                    |
| 📋 List Users       | Display system users                    |

---

## ▶️ Run Project

```bash
git clone https://github.com/YOUR-USERNAME/linux-user-management.git
cd linux-user-management
chmod +x user-management.sh
sudo ./user-management.sh
```
